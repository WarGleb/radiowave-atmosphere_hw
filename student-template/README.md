## Учёт времени

Чтобы мы могли оценить, сколько часов занимает каждое задание, фиксируйте начало и конец работы:

- садитесь за задание: дважды щёлкните `start.bat` (при запросе введите номер, например `dz1`);
- заканчиваете работу на сегодня: дважды щёлкните `stop.bat`.

Скрипты дописывают московское время в `worklog.csv`, делают коммит и отправляют его на GitHub. Если забыли нажать `stop.bat`, при следующем запуске `start.bat` вас об этом предупредят: запустите сначала `stop.bat`. Время нужно для настройки объёма заданий и на оценку не влияет. Нужен установленный Git и вход в GitHub на компьютере.
