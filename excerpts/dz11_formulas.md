# ДЗ-11. Лист справки

Раздел «Для сверки» открывайте после того, как нашли формулу сами. Остальные формулы даны в условии.

### [1, разд. 8.2.2, ф. (8.22), с. 18 файла]

**Для сверки.** Профиль Хуфнагеля–Вэлли зависит от высоты $h$, приземного значения $A = C_n^2(0)$ и скорости ветра $v$:

$$C_n^2(h) = 0{,}00594\left(\frac{v}{27}\right)^2(10^{-5}h)^{10}e^{-h/1000} + 2{,}7\cdot10^{-16}e^{-h/1500} + A\,e^{-h/100}.$$

### [1, разд. 8.2.2, «Scintillation», ф. (8.23), (8.25), с. 19 файла]

**Для сверки.** Индекс мерцаний точечного приёмника на нисходящей линии

$$\sigma_I^2 = \exp\left[\frac{0{,}49\sigma_R^2}{(1 + 1{,}11\sigma_R^{12/5})^{7/6}} + \frac{0{,}51\sigma_R^2}{(1 + 0{,}69\sigma_R^{12/5})^{5/6}}\right] - 1,$$

$$\sigma_R^2 = 2{,}25\,k^{7/6}\sec^{11/6}\zeta\int_{h_0}^{H}C_n^2(h)\,(h - h_0)^{5/6}\,dh.$$

Приближение слабой турбулентности для профиля Хуфнагеля–Вэлли справедливо до угла места 30° при слабой турбулентности и до 60° при сильной (с. 20 файла). Проверка: на 1550 нм в зените для равнины $\sigma_R^2 \approx 0{,}06$.

### [2, разд. IV.A, ф. (4), (6), (7), (8), с. 539]

**Для сверки.** Затухание в тумане по видимости $V$ (км) при пороге пропускания 2 %: $\alpha = \dfrac{3{,}912}{V}\left(\dfrac{\lambda}{550}\right)^{-q}$ дБ/км, $\lambda$ в нм. Показатель $q$: 1,6 при $V > 50$; 1,3 при $6 < V < 50$; $0{,}16V + 0{,}34$ при $1 < V < 6$; $V - 0{,}5$ при $0{,}5 < V < 1$; 0 при $V < 0{,}5$. Для сравнения в [2]: снег $58/V$, дождь $2{,}9/V$ дБ/км. Для порога 5 % в числителе стоит 13 вместо 3,912.

### [3, разд. 5.1.1–5.1.2, ф. (6), (8a)]

**Для сверки.** Профиль $C_n^2(h) = 8{,}148\cdot10^{-56}v_{rms}^2h^{10}e^{-h/1000} + 2{,}7\cdot10^{-16}e^{-h/1500} + C_0e^{-h/100}$ м$^{-2/3}$ (то же, что $0{,}00594(W/27)^2(10^{-5}h)^{10}\ldots$ при $W = v_{rms}$). Радиус Фрида $r_0 = \left(0{,}423\,k^2\sec\zeta\int_{h_0}^{Z}C_n^2(h)\,dh\right)^{-3/5}$.


### [4, п. (VII) «Atmospheric seeing», ф. (23), (24), с. 13 файла]

**Для сверки.** Дисперсия угла прихода $\beta^2 = 2{,}91\int C_n^2(h)\,dh\,D_R^{-1/3}\sec\theta$ (23), упрощённо $\beta^2 = 0{,}182\,(D_R/r_0)^{5/3}(\lambda/D_R)^2$ (24). В ДЗ-11 та же форма применена к передающей апертуре $D$.

### [5, ф. (22) по arXiv:1405.0160]

**Для сверки.** Воздушная масса: $m = 1/\left[\cos z + 0{,}50572\,(96{,}07995 - z)^{-1{,}6364}\right]$, $z$ - зенитный угол в градусах. Через угол места $\varepsilon = 90° - z$: $\cos z = \sin\varepsilon$, $96{,}07995 - z = \varepsilon + 6{,}07995$; в условии константа округлена до 6,08. Оригинал: Applied Optics 28(22), 4735 (1989).
