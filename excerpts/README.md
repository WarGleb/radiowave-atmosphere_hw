# Листы справки

В этой папке лежат короткие справки к заданиям: формулы и пояснения, составленные авторами задания по источникам, без копий страниц. Заголовок каждого раздела совпадает со ссылкой в условии, например `### [2, с. 309, ф. (7.49)]`.

Листы нужны, чтобы решить задание без выхода в интернет. Проверить формулу по оригиналу можно по ссылке: `python tools/open_source.py dz1 2 309` сначала покажет нужный раздел листа справки, затем откроет оригинал, если он у вас есть.
