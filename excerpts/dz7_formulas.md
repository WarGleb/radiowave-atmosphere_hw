# ДЗ-7. Лист справки

Частота $f$ в ГГц, давления в гПа, $T$ в К, $\theta = 300/T$. Раздел «Для сверки» открывайте после того, как нашли формулу сами. Числа таблиц 1 и 2 здесь не приводятся.

### [1, Annex 1, разд. 1, ф. (1), (2a), (2b), (3), с. 3–4]

**О чём.** Удельное затухание — мнимая часть комплексной рефрактивности, сумма вкладов отдельных линий.

**Для сверки.**

$$\gamma = 0{,}1820\,f\,\left(N''_{O_2}(f) + N''_{H_2O}(f)\right)\ [\text{дБ/км}],$$

$$N''_{O_2}(f) = \sum_i S_iF_i + N''_D(f), \qquad N''_{H_2O}(f) = \sum_i S_iF_i,$$

$$S_i = a_1\cdot10^{-7}\,p\,\theta^3\exp\left[a_2(1-\theta)\right]\ \text{(кислород)}, \qquad S_i = b_1\cdot10^{-1}\,e\,\theta^{3{,}5}\exp\left[b_2(1-\theta)\right]\ \text{(водяной пар)}.$$

Здесь $p$ — давление сухого воздуха, $e$ — давление пара, $p_{полн} = p + e$.

### [1, Annex 1, разд. 1, ф. (4)–(7), с. 7]

**О чём.** Давление пара по плотности, форма линии и её ширина.

**Для сверки.**

$$e = \frac{\rho\,T}{216{,}7},$$

$$F_i = \frac{f}{f_i}\left[\frac{\Delta f - \delta(f_i - f)}{(f_i - f)^2 + \Delta f^2} + \frac{\Delta f - \delta(f_i + f)}{(f_i + f)^2 + \Delta f^2}\right],$$

$$\Delta f = a_3\cdot10^{-4}\left(p\,\theta^{0{,}8-a_4} + 1{,}1\,e\,\theta\right)\ \text{(O}_2), \qquad \Delta f = b_3\cdot10^{-4}\left(p\,\theta^{b_4} + b_5\,e\,\theta^{b_6}\right)\ \text{(H}_2\text{O}).$$

Поправки (ф. (6b), (7)):

$$\Delta f \to \sqrt{\Delta f^2 + 2{,}25\cdot10^{-6}}\ \text{(O}_2), \qquad \Delta f \to 0{,}535\,\Delta f + \sqrt{0{,}217\,\Delta f^2 + \frac{2{,}1316\cdot10^{-12}\,f_i^2}{\theta}}\ \text{(H}_2\text{O}),$$

$$\delta = (a_5 + a_6\theta)\cdot10^{-4}(p + e)\,\theta^{0{,}8}\ \text{(O}_2), \qquad \delta = 0\ \text{(H}_2\text{O}).$$

Контроль: при $T = 288{,}15$ К, $p_{полн} = 1013{,}25$ гПа, $\rho = 7{,}5$ г/м³ получается $\gamma_{O_2}(60\ \text{ГГц}) \approx 14{,}5$ дБ/км и $\gamma_{H_2O}(22{,}235\ \text{ГГц}) \approx 0{,}18$ дБ/км.

### [1, Annex 1, табл. 1 и 2, с. 8–10]

**О чём.** Спектроскопические данные: $f_0, a_1,\dots,a_6$ для кислорода (44 линии) и $f_0, b_1,\dots,b_6$ для водяного пара (35 линий, последняя — псевдолиния на 1780 ГГц вместо континуума). Числа берите из [1].

### [1, Annex 1, ф. (8), (9), с. 10]

**О чём.** Непрерывная часть для сухого воздуха: недебаевский спектр кислорода (ниже 10 ГГц) и индуцированное давлением поглощение азота (выше 100 ГГц).

**Для сверки.**

$$N''_D(f) = f\,p\,\theta^2\left[\frac{6{,}14\cdot10^{-5}}{d\,\left[1 + (f/d)^2\right]} + \frac{1{,}4\cdot10^{-12}\,p\,\theta^{1{,}5}}{1 + 1{,}9\cdot10^{-5}f^{1{,}5}}\right], \qquad d = 5{,}6\cdot10^{-4}(p + e)\,\theta^{0{,}8}.$$

### [1, разд. 3, ф. (24), (25a)–(25d), с. 16–17]

**О чём.** Дисперсия — действительная часть рефрактивности $N'$ и фазовая дисперсия.

**Для сверки.**

$$\varphi = -1{,}2008\,f\,\left(N'_{O_2}(f) + N'_{H_2O}(f)\right)\ [\text{град/км}], \qquad N'_{O_2} = \sum_i S_iF_i' + N'_D, \quad N'_{H_2O} = \sum_i S_iF_i',$$

$$F_i' = \frac{f}{f_i}\left[\frac{(f_i - f) + \delta\Delta f}{(f_i - f)^2 + \Delta f^2} - \frac{(f_i + f) + \delta\Delta f}{(f_i + f)^2 + \Delta f^2}\right], \qquad N'_D = \frac{-6{,}14\cdot10^{-5}\,p\,\theta^2 f^2}{f^2 + d^2}.$$

Контроль: у земли ($T = 288{,}15$ К, $p = 1004{,}4$ гПа, $e = 8{,}56$ гПа) $N'(60\ \text{ГГц}) \approx -0{,}08$ ppm, $N'$ меняет знак вблизи 60 ГГц.
