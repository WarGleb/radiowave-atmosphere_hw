# ДЗ-10. Лист справки

Внешних источников для этого задания нет: все формулы даны в условии. Здесь собраны только контрольные соотношения.

**Для сверки.** Рэлей: $P(p<x) = 1-e^{-x}$, поэтому для 1 % времени $x = -\ln 0{,}99 \approx 0{,}01005$, то есть запас $\approx 20$ дБ. Логнормальная модель: запас на 99 % равен $2{,}326\,\sigma_{ln}$. Райс при $K \to 0$ переходит в Рэлея, при $K \to \infty$ — в постоянную амплитуду.

**Для сверки.** $T_c = 1/\sqrt{\dot f_D}$: при 100 Гц/с получается 100 мс, при 1000 Гц/с — 31,6 мс. Ускорение растёт пропорционально несущей.

**Для сверки.** Функция Маркума: $Q_1(a, b) = \int_b^\infty x\,e^{-(x^2+a^2)/2} I_0(ax)\,dx$; `scipy.stats.ncx2.sf(b**2, 2, a**2)`.
