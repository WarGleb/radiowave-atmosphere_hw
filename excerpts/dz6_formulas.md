# ДЗ-6. Лист справки

Время в процентах, $\ln$ натуральный. Раздел «Для сверки» открывайте после того, как нашли метод сами. Цифровые карты (интенсивность дождя, высота нулевой изотермы) в лист не входят: их берёте сами.

### [1, Annex 1, шаги 1–8, с. 2–5, ф. (1)–(8)]

**О чём.** Статистика интенсивности дождя в точке. Для 0,01 % среднего года $R_{0,01}$ берётся из готовой карты, вероятность дождя $P_0$ считается по месячным данным (осадки и температура).

**Для сверки.** Месячная интенсивность и вероятность дождя ($t$ в °C):

$$r_{ii} = 0{,}5874\,e^{0{,}0883\,t_{ii}} \ (t_{ii} \ge 0), \qquad r_{ii} = 0{,}5874 \ (t_{ii} < 0), \qquad P_{0,ii} = \frac{100\,MT_{ii}}{24\,N_{ii}\,r_{ii}}\ (\%),$$

(при $P_{0,ii} > 70$ берётся 70 с пересчётом $r_{ii}$ по шагу 6b),

$$P_0 = \frac{\sum_{ii=1}^{12} N_{ii}\,P_{0,ii}}{365{,}25}.$$

Распределение интенсивности дождя в месяце логнормальное, с $\sigma = 1{,}26$ для $\ln R$:

$$P_{ii}(R > R_{ref}) = P_{0,ii}\,Q\left(\frac{\ln R_{ref} + 0{,}7938 - \ln r_{ii}}{1{,}26}\right), \qquad Q(x) = \frac{1}{\sqrt{2\pi}}\int_x^\infty e^{-t^2/2}\,dt.$$

Годовая статистика: $P(R > R_{ref}) = \sum N_{ii} P_{ii}(R > R_{ref})/365{,}25$, $R_p$ находится подбором $R_{ref}$.

### [2, разд. 1, ф. (1)–(5), табл. 1–4]

**О чём.** Коэффициенты закона $\gamma_R = kR^\alpha$ для произвольной поляризации и угла места ($\theta$ — угол места, $\tau$ — наклон поляризации относительно горизонтали, $\tau = 45°$ для круговой).

**Для сверки.**

$$k = \frac{k_H + k_V + (k_H - k_V)\cos^2\theta\cos 2\tau}{2}, \qquad \alpha = \frac{k_H\alpha_H + k_V\alpha_V + (k_H\alpha_H - k_V\alpha_V)\cos^2\theta\cos 2\tau}{2k}.$$

$k_H$, $\alpha_H$, $k_V$, $\alpha_V$ — по формулам (1)–(3) и табл. 1–4 [2], см. [лист справки ДЗ-2](dz2_formulas.md). Контроль: 30 ГГц, $\theta = 30°$, $\tau = 90°$: $k \approx 0{,}2305$, $\alpha \approx 0{,}9176$.

### [3, раздел «recommends», п. 2, с. 1]

**О чём.** $h_R = h_0 + 0{,}36$ км, где $h_0$ — средняя годовая высота нулевой изотермы над уровнем моря (из цифровой карты [3]).

### [4, разд. 2.2.1.1, шаги 1–10, ф. (1)–(8), с. 7–8]

**О чём.** Долговременная статистика затухания в дожде на наклонной трассе. Вход: $R_{0,01}$, $h_s$, $\beta$, широта $\varphi$, $f$; эффективный радиус Земли $R_e = 8500$ км.

**Для сверки.** Для $\beta \ge 5°$:

$$L_s = \frac{h_R - h_s}{\sin\beta}, \qquad L_G = L_s\cos\beta, \qquad \gamma_R = k\,R_{0,01}^{\alpha},$$

$$r_{0,01} = \frac{1}{1 + 0{,}78\sqrt{L_G\gamma_R/f} - 0{,}38\,(1 - e^{-2L_G})},$$

$$\zeta = \arctan\frac{h_R - h_s}{L_G\,r_{0,01}}\ \text{(град)}, \qquad L_R = \begin{cases} L_G r_{0,01}/\cos\beta, & \zeta > \beta \\ (h_R - h_s)/\sin\beta, & \text{иначе} \end{cases}$$

$$\chi = 36 - |\varphi|\ (|\varphi| < 36°),\ \text{иначе } 0, \qquad \nu_{0,01} = \frac{1}{1 + \sqrt{\sin\beta}\left[31\left(1 - e^{-\beta/(1+\chi)}\right)\dfrac{\sqrt{L_R\gamma_R}}{f^2} - 0{,}45\right]},$$

$$L_E = L_R\,\nu_{0,01}, \qquad A_{0,01} = \gamma_R L_E.$$

Для других $p$ ($0{,}001\ \% \le p \le 5\ \%$), формула (8):

$$A_p = A_{0,01}\left(\frac{p}{0{,}01}\right)^{-\left(0{,}655 + 0{,}033\ln p - 0{,}045\ln A_{0,01} - (1-p)\sin\beta\cdot c\right)},$$

где $c = 0$ при $p \ge 1$ % или $|\varphi| \ge 36°$; $c = -0{,}005(|\varphi| - 36)$ при $p < 1$ %, $|\varphi| < 36°$, $\beta \ge 25°$ (в [4] эта поправка обозначена греческой буквой «бета», здесь $c$, чтобы не путать с углом места); иначе $c = -0{,}005(|\varphi| - 36) + 1{,}8 - 4{,}25\sin\beta$. Контроль для варианта 0: $A_{0,01} \approx 24{,}36$ дБ, $A_{0,1} \approx 8{,}94$ дБ.

### [4, разд. 2.2.1.3, шаги 1–5, с. 11]

**О чём.** Логнормальная подгонка распределения затухания.

**Для сверки.** $p_i = P_i/P_0$ (только $P_i \le P_0$); по точкам $\left(Q^{-1}(p_i), \ln A_i\right)$ методом наименьших квадратов находится прямая

$$\ln A_i = \sigma\,Q^{-1}(p_i) + \mu.$$

### [4, разд. 2.2.4.1, ф. (27)–(29), с. 13]

**О чём.** Разнесённый приём: совместная вероятность превышения на двух станциях. Корреляция интенсивности дождя между станциями на расстоянии $d$ (км):

$$\rho_r = 0{,}7\,e^{-d/60} + 0{,}3\,\exp\left[-(d/700)^2\right].$$

Контроль: при $d = 500$ км $\rho_r \approx 0{,}180$.
