# ДЗ-9. Лист справки

Раздел «Для сверки» открывайте после того, как нашли формулу сами.

### [1, разд. 3, ф. (69), (70), с. 24]

**Для сверки.** Шумовая температура неба на антенне станции:

$$T_{sky} = T_{mr}\left(1 - 10^{-A/10}\right) + 2{,}7\cdot10^{-A/10}\ [\text{К}],$$

$A$ — полное затухание в атмосфере без сцинтилляций, дБ. Если температура у земли $T_s$ известна, $T_{mr} = 37{,}34 + 0{,}81\,T_s$; без местных данных допустимо $T_{mr} = 275$ К.

### [1, разд. 4.1, шаги 1–6, ф. (71)–(76), с. 25]

**Для сверки.** Метод применим при $6 \le f \le 55$ ГГц, $\theta \le 60°$. Для $9 \le f \le 36$ ГГц $C_f = 26\lg f + 4{,}1$. Для $9 \le f \le 20$ ГГц $V(f) = 12{,}8\,f^{0{,}19}$, для $20 < f \le 40$ ГГц $V = 22{,}6$; $C_A = V(f)\lg A_p$. Улучшение за счёт наклона $C_\tau = -10\lg\left[1 - 0{,}484(1 + \cos 4\tau)\right]$ ($=0$ при $\tau = 45°$). Угол места: $C_\theta = -40\lg\cos\theta$. Разброс углов капель: $C_\sigma = 0{,}0053\,\sigma^2$, $\sigma = 0, 5, 10, 15°$ для 1; 0,1; 0,01; 0,001 % времени. Итог:

$$XPD_{rain} = C_f - C_A + C_\tau + C_\theta + C_\sigma.$$

### [1, разд. 4.1, шаги 7–8, ф. (77), (78), с. 25]

**Для сверки.** $C_{ice} = XPD_{rain}\,(0{,}3 + 0{,}1\lg p)/2$, $XPD_p = XPD_{rain} - C_{ice}$, $p$ в процентах.

### [3, разд. 5, ф. (13), табл. 1, с. 13; разд. 6, ф. (14), с. 17]

**Для сверки.** Медианный техногенный шум на частоте $f$ (МГц), $0{,}3 \le f \le 250$ МГц: $F_{am} = c - d\lg f$ дБ над $kT_0b$. Постоянные ($c$; $d$): город 76,8; 27,7; жилая зона 72,5; 27,7; сельская местность 67,2; 27,7. Галактический шум до 100 МГц: $F_{am} = 52 - 23\lg f$. Внешний коэффициент шума $f_a = p_n/(kT_0b)$, $T_0 = 290$ К.

### [3, разд. 2, ф. (5), с. 3]

**Для сверки.** Коэффициент шума системы $f = f_a - 1 + f_c f_t f_r$; для фидера при 290 К $f_t = l_t$ (потери в разах).
