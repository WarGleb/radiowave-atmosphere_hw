## Главная идея: данные вы находите сами

В заданиях нет готовых констант и коэффициентов. Нужно найти их в рекомендациях МСЭ-Р, статьях и справочниках, проверить версию и записать, откуда взято каждое число. Это умение важнее самой формулы: на практике рекомендация выходит в новой версии, карты обновляются, пакеты отстают, и отвечает за результат тот, кто считает.

Ответы для варианта 0 в конце каждого задания работают как проверка выбора источников. Если вы взяли значение не из той версии, расхождение увидите сразу.

Что для этого есть:

- [HOWTO_sources.md](HOWTO_sources.md): где искать, как читать рекомендацию, как записывать;
- в каждом задании раздел «Типичные ошибки» и ответы контрольного варианта 0 для самопроверки;
- [student-template/](student-template/): шаблон репозитория с README, SOURCES.md, заготовкой решения и автоматической проверкой по контрольному варианту.

## Учёт времени

В вашем репозитории (по шаблону) лежат `start.bat` и `stop.bat`. Начинаете работу над заданием: дважды щёлкните `start.bat` и введите номер (например, `dz1`). Закончили на сегодня: `stop.bat`. Скрипты записывают московское время в `worklog.csv` и отправляют запись на GitHub. Зачем это нужно: чтобы подобрать объём заданий; на оценку время не влияет. Нужны Git и вход в GitHub на компьютере.

## Результат: репозиторий на GitHub

Работа сдаётся в **приватном репозитории** на GitHub, в который вы добавляете преподавателя (роль Read). Решения студентов не публикуются: так никто не может скопировать чужую работу. Проверка выполняется преподавателем по скрытым эталонам; вам сообщается «выполнено / не выполнено» по каждому заданию. После защиты репозиторий можно сделать публичным и использовать как портфолио. Как создать репозиторий и что в него положить, написано в [HOWTO_github.md](HOWTO_github.md).

## Среда расчёта

Подойдёт любая: Python, MATLAB, Mathcad, Octave, Julia, C++, Excel. Для автоматической проверки в шаблоне нужен Python, но результат можно сверить и вручную. Эталонное решение у преподавателя написано на MATLAB.

## Варианты

Номер варианта равен номеру студента в списке группы: $n = 1, 2, 3\dots$ Исходные данные считаются по формулам в каждом задании, например «$\tau = 5 + 0{,}2\,n$ пс». Запись $\mathrm{mod}(n, k)$ означает остаток от деления $n$ на $k$.

Вариант 0 — контрольный, ответы к нему приведены в конце каждого задания. Порядок работы:

1. Найдите источники, заполните SOURCES.md.
2. Напишите программу и прогоните её на варианте 0.
3. Сверьте ответы (допуск 1 %, если в задании не указано иное). Расхождение означает ошибку в программе или в источнике, а не в ответах.
4. Только после этого считайте свой вариант.

## Что сдавать

- Адрес приватного репозитория GitHub, куда добавлен преподаватель.
- В репозитории файл `results/result_dzK.json` с результатами вашего варианта (формат: `python src/solution.py --dz dzK --variant n --json results/result_dzK.json`).
- В репозитории: README (постановка, метод, результаты, графики), SOURCES.md, программа, таблица результатов для варианта 0 и для своего варианта, графики, лицензия.
- Короткие ответы на вопросы для защиты, по 2–4 предложения, в README или отдельным файлом.

## Критерии оценки (100 баллов)

| Что проверяется | Баллы |
|---|---|
| Источники и умение их находить (SOURCES.md), подробно ниже | 15 |
| Контрольный вариант совпал с ответами (±1 %) | 15 |
| Свой вариант посчитан верно | 25 |
| Графики: правильные величины, оси, единицы, легенда | 10 |
| Воспроизводимость: программа запускается по инструкции из README, тест проходит | 10 |
| Ответы на вопросы для защиты: объяснена физика, а не пересказана формула | 15 |
| Оформление портфолио: README читается, есть выводы и ограничения, репозиторий аккуратный | 10 |

Из 15 баллов за источники:

| Что оценивается | Баллы |
|---|---|
| Выбран подходящий первичный источник (стандарт, рекомендация, учебник или статья), а не пересказ в блоге или на форуме; в ДЗ-11 это закон распределения фотонов, в других ДЗ — поставленные в условии «найдите сами» | 5 |
| Указано точное место: раздел, страница, номер формулы, версия и дата; ссылка или DOI/ISBN открывается | 4 |
| Значение или формула проверены независимо вторым источником или расчётом | 3 |
| Записаны расхождения версий и то, что искали, но не нашли | 3 |

Шкала: 85–100 — «отлично», 70–84 — «хорошо», 50–69 — «удовлетворительно».

Оценка не выше «удовлетворительно», если нет SOURCES.md, ссылки на источники не открываются, или нет ответов на вопросы для защиты.

## Честная работа

- Разрешено пользоваться ИИ-помощниками, пакетами и чужим кодом, если это указано в README (раздел «Использование ИИ») и результат проверен по первоисточнику.
- Нельзя выдавать за найденный источник, который вы не открывали.
- Нельзя публиковать чужие решения и таблицу вариантов всей группы.
- Совпадение решений двух студентов с одинаковыми ошибками и одинаковым SOURCES.md разбирается на защите.
